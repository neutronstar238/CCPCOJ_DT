# v1.14.1 SSH 表格布局修复

原因：表格继承 `white-space: nowrap`，新增私钥路径、解锁口令两个 100% 宽输入框在同一单元格内横向排列，越过单元格边界盖住“最近操作结果”。旧输入框最小宽度也会挤占窄列。

修复：SSH 表格使用固定列布局；两个输入框块级纵向排列、间隔 8px，宽度限制在单元格内。表格文字可换行，结果列独立；端口和选择列保留足够宽度。小窗口在既有表格容器内横向滚动。

真实 Edge 浏览器验证 2048、1440、1280、900、390 像素窗口：全部 SSH 输入框处于所属单元格边界内，解锁口令位于路径输入框下方，与结果列不相交。私钥默认值、通用灰色提示、待绑定清单预览、批量绑定和加密保存回归通过。截图使用测试资料并遮挡路径。

未修改个人默认私钥或机位清单，也未连接、部署任何远端机器。个人私钥路径由本机 DPAPI 设置读取，未写入灰色提示、源码或发布包。
