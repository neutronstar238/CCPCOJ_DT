# v1.12.0 网段扫描与选手端导入验证

日期：2026-11-06。此次新增工作台扫描流程，沿用已有 CSGArena 安装与自动登记实现；没有修改管控程序或 OJ 源码。

## 已验证

- 多组完整起止 IPv4、跨网段展开、去重、尾号范围、无效地址／超大范围拦截。
- 本机临时 TCP 监听实际探测成功，未发送登录认证；TCP 拒绝被标记为响应，Windows ping 返回成功码但没有 TTL 回复时不误计在线。
- 扫描数量／进度／响应列表、取消后停止发起新探测、鉴权及与其他部署任务互斥。
- 浏览器输入起止 IP，扫描 3 个模拟地址，显示 2 台在线响应；默认勾选管理端口可连接机器。
- 统一账号密码、逐 IP 覆盖、默认 sudo 继承登录密码、统一独立 sudo 及单机 sudo 覆盖。
- 扫描请求只包含范围与探测端口，不包含已填写的账号密码。
- 只把勾选 IP 加入清单，重复／已有 IP 跳过，未响应的间隔地址不被补入；导入本身不执行部署。
- 浏览器保存后 DPAPI 中保留正确的机位和服务端绑定，刷新能恢复部署清单；轮询不会清空已填写的凭据。
- 结果表输入控件均在各自列内，没有系统／端口字段挤占下一列。
- 自动登记回归测试确认：分发后的客户端调用 `setup`，探测指定服务端地址并调用本机登记 API；enrolled 和 installed 同时成功才记录完成。独立身份仍由每台客户端生成。

相关 Python 测试 25 项、前端测试 30 项通过。Edge 实际页面联调使用模拟探测结果；网络探测的真实连接只到本机临时监听端口。未扫描真实赛场网段，也未在真实赛场主机执行安装。

截图 `arena-scan.png` 使用文档示例 IP 和测试凭据（密码字段隐藏），本机临时资料路径已替换为测试目录描述。

## 使用边界

每次最多 4096 地址、32 并发探测；不响应不能证明关机，系统类型只是端口建议。Linux SSH / Windows WinRM 及凭据、信任关系仍需满足部署前置条件。选择结果后先加入部署清单，再核对完整清单并点击一键部署；下方部署操作作用于该页全部已配置目标。

真实 Linux／Windows 安装、心跳及赛场策略仍需提供具体网段和隔离目标后验收。
