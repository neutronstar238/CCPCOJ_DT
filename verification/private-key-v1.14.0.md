# v1.14.0 私钥登录验证

完成 SSH 管理、OJ 节点、管控服务端／选手端、扫描统一／单机凭据的外部私钥字段；新增用户名默认 root。个人默认路径由本机 DPAPI 文件提供，灰色提示、源码和发布包不内置实际个人路径。

- 新增 6 项 Python 回归：带口令 Ed25519、解锁空格保留、每任务密钥去重、错误路径／口令、日志脱敏、Windows SSH inventory、无绑定清单保存与部署阻止、本机默认隔离、真实本地 SSH 密钥认证与禁止密码回退、DPAPI 保存、远端任务不携带私钥路径／口令。
- Python 回归分组通过，SSH 管理组单独运行以隔离已有夹具时序问题；SSH 配置测试用进程内 FQDN mock 隔离本机 DNS 等待。
- 32 项 JavaScript 回归通过。
- 真实浏览器检查：各登录编辑器 root／本机私钥默认值、通用灰色提示、待绑定清单预览、批量绑定、加密保存；没有发起部署。
- 真实本地 SSH/SFTP 夹具验证外部加密密钥登录、任务载荷与文件清理；有效密码不会掩盖不被接受的私钥。
- 真实 WSL Ansible 通过 Windows 网络连接器，分别以 Paramiko 和 OpenSSH 使用解锁后的私钥执行只读 raw 任务；控制器成功与失败退出都清理私有临时目录。证书校验的 WinRM HTTPS 转发回归通过。

仅本机运行资料导入已验证成功的 334 个选手机 IP，按同网段连续地址合并，不跨越空洞或失败地址；两台认证失败目标不在清单。个人私钥和该清单不进入发布包。本机没有服务端配置，因此导入条目保持待绑定，未部署、启动或登记远端客户端。

限制：Windows 私钥路径生成的 OpenSSH 连接已验证传输和认证，未在真实 Windows 赛场主机执行安装／PowerShell 服务流程；已有 WinRM 密码流程保留。WSL 中目标主机指纹仍需受信任。
