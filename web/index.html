本地部署 · WSL

目录是所选发行版内的 Linux 绝对路径，例如 /srv/csgoj-local 或 /mnt/d/csgoj-local；Web 和评测数据分别放在 web / judge 子目录。数据库建议放在发行版的 Linux 文件系统内；WSL 虚拟磁盘所在 Windows 盘符由 WSL 管理。需要发行版内 Docker 和 systemd，不能使用 Docker Desktop 共享守护进程。缺少 Docker 时首次部署会通过 apt 安装。启动服务后自动保活，关闭工作台不停止本地服务；如需完全关闭，可执行 wsl --terminate 发行版名称。

使用说明
节点配置
添加任意数量的 Web 与评测机，或下载 XLSX 模板填写后导入。导入会先显示预览；确认后显示完整节点清单。导入和保存不会执行部署。
备用列使用 0 / 1：0 表示启用，1 表示备用。同名节点合并更新，未列出的现有节点保留。密码可留空后在页面补填；Excel 中填写的密码是明文。
部署程序先存本地
在“版本与镜像分发”上传本地 Linux 部署程序，或查询 Release 后点击“下载并选用部署程序”。程序缓存到 Windows 资料目录，再由本工具通过 SFTP（与 SCP 同属 SSH 文件传输）上传服务器；不在服务器上临时下载部署程序。镜像标签与部署工具 Release 分别填写。
批量更新
点击“同步服务器版本与镜像”，勾选节点并逐台选择目标版本，确认后点击“部署 / 更新所选节点”。已有完整配置时保留更新，无旧配置时首次初始化。服务器已有目标镜像直接使用，缺少时从 Windows 缓存补齐。Web 自动先于评测机执行。备用节点只安装依赖、缓存镜像并做断网自检，不启动站点或接入评测。
状态与主备切换
服务器连接状态与业务服务状态分开展示。检测发现已部署的启用节点服务停止时，可一键启动原容器，再检查 Web 登录/样式或评测心跳。SSH 无法连接可能是网络或认证问题，不能直接断言主机已关机。容器缺失但有旧数据时请先恢复容器，不能重新初始化；备用使用启用备用功能。在线检测、启动、备份、启用备用、重绑评测机和恢复主机设置可以独立使用。Web 切换是受控停机迁移，不是自动双主或实时同步。
SSH 和主机设置
sudo 填普通账号的 sudo 密码；su 填 root 密码。密钥登录不等于 sudo 提权。关闭图形界面、永不休眠与性能模式分别勾选。永不休眠会阻止系统睡眠、挂起、休眠请求，不重启服务器。
IP 变化和离线准备
保留节点名与密钥名，修改 IP 后保存，再检测状态。Web IP 改变后，用“更新评测机 Web 地址”更新关联评测机。断外网前须完成所有镜像和系统依赖准备；镜像缓存不包含未安装的 Ubuntu 软件包。
资料与适用范围
默认资料目录为 %LOCALAPPDATA%\CSGOJDeploy，包含 DPAPI 配置、keys、tools、logs 和 backups。已有官方部署会先验证原配置和凭据再接管，残留数据或不完整容器会停止并提示检查。完整迁移应先在空白测试环境演练。最终开赛验收仍需实际提交测试程序。
