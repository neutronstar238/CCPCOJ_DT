# v1.10.3 · 首次公开发布

这是 CCPCOJ_DT（CSGOJ 部署工作台）的第一次公开发布，包含目前完整功能，而不是一个需要覆盖旧版本的补丁包。工作台版本为 v1.10.3；所管理的 OJ 镜像和官方 Linux 部署程序版本独立选择。

## 下载内容

- `CSGOJ-Deployment-Console-Windows-v1.10.3.zip`：可直接解压运行的 Windows x64 完整包。
- `CSGOJ-Deployment-Console-Windows-v1.10.3.zip.sha256`：上述完整 ZIP 的 SHA256。
- GitHub 自动附带的 Source code 归档是仓库源码，不包含已构建的 Windows 程序。

完整包包含程序、网页、节点 XLSX 模板、源码、操作文档、文字验证记录、逐文件 SHA256 清单及第三方运行依赖许可。**不包含验收截图、用户配置、SSH 私钥、业务密码导出、生产日志、数据库备份、OJ Docker 镜像或上游 Linux 部署程序。**

## 适用环境与启动

管理电脑使用 Windows x64。目标服务器主要面向 Ubuntu 24.04 LTS / amd64，提前准备 SSH 登录账号及所需提权权限。本地部署使用 WSL 2 Ubuntu 24.04、systemd 和发行版自身的 Docker。

下载 ZIP 和校验文件后，在 PowerShell 使用 `Get-FileHash -Algorithm SHA256 .\CSGOJ-Deployment-Console-Windows-v1.10.3.zip` 核对摘要。完整解压后双击 `启动部署工作台.cmd`。无需预先安装 Python、Node.js、Ansible 或 PuTTY；程序仅监听本机回环地址。关闭网页不会必然结束后台程序，退出工作台也不会自动关闭已部署的业务服务。

完整指南：[README](https://github.com/neutronstar238/CCPCOJ_DT/blob/main/README.md)。

## 完整功能

### 1. SSH 密钥与连接管理

可独立于 OJ 节点生成或复用 Ed25519 密钥、追加服务器公钥、测试纯密钥登录、扫描已有 web / pcj 前缀密钥并预览导入。修改 IP、用户名和端口时可保留私钥，更新使用该私钥的已保存节点及本机 SSH 别名。主机密钥变化和别名冲突会停止并提示；不会覆盖其他私钥或替换服务器现有公钥列表。登录与 sudo 提权分别处理。

### 2. 节点配置与 XLSX 导入

支持 Web、PCJ 评测机、启用与备用节点，配置连接、项目目录、Web 绑定、pods 和初始化资料。XLSX 先预览后确认，按节点名合并；导入不自动部署。普通设置自动保存，部署等操作显式执行。主机选项包括关闭图形界面、永不休眠、性能模式，并保存原设置供恢复。

### 3. 版本获取、镜像缓存及内网分发

查询官方公开 Release（包含已发布 exp 标签）和镜像版本，选择或手动输入目标标签；也可导入本地 Linux 部署程序、Docker-save 归档。输入版本初始留空，不自动使用某个版本。

镜像下载支持腾讯云、Docker Hub 和自定义优先源，失败按源回退但不改变目标版本。直接访问 Registry V2，不要求 Docker Desktop；最多四层并发，复用已校验缓存，检查内容摘要与 Linux amd64 平台后生成标准归档。自动代理候选需通过 CONNECT 检查，排除 53000 控制端口，不改永久代理设置。

新增已有本地镜像识别：扫描工具缓存及常用本地目录，读取已运行的本机 Docker；根据归档真实标签和平台显示候选，可应用文件或导出 Docker 镜像到缓存。不会自动启动 Docker 或连接远程 Docker。归档删除需要二次确认。

分发只执行内网上传、SHA256 校验及 docker load，不替换应用。下载、导入和刷新读取同一个资料目录。仅更新程序时默认不拉取 MySQL、Nginx、phpMyAdmin；首次 Web 初始化需要准备这些依赖。

### 4. 批量更新与首次初始化

同步每台服务器运行版本和已有镜像，逐节点选择目标版本，支持一键勾选全部 PCJ 或 Web。优先使用服务器已有目标镜像，缺少时才从本机缓存上传。

执行前检查旧配置、容器、数据和挂载：已有完整部署保留配置更新，符合条件的既有部署验证凭据后接管，空白节点初始化；不把异常或残留数据当成空白。Web 更新只替换应用容器并保留 SQL 等服务、口令与数据；评测机保留账号、pods 和绑定关系。失败记录并停止批次。

### 5. 状态、启动、pods 与受控迁移

分别显示 SSH 连接和业务服务状态、当前版本、检测时间；PCJ 单独显示最近检测时实际运行 pods 数。已有服务可一键启动，可在维护确认后调整 pods 或更新评测机 Web 地址。

支持 Web 冷备份、受控主备迁移、数据校验和失败恢复，原数据及快照保留。这不是双主、实时复制或无人值守故障切换。

### 6. 数据库目录与 SSD 迁移

首次 Web 初始化可选数据库目录。已部署站点可检测项目、数据库、代码、题库与 Docker 所在设备和挂载；在维护时段迁移到预先挂载的空目录，校验副本，以 bind 挂载保留官方路径，并记录磁盘 UUID 防止掉盘后误写。提供未完成迁移恢复入口，不格式化磁盘、不自动清除旧副本。

### 7. 本地 WSL Web / PCJ 部署

独立选择 WSL 发行版和 Linux 路径，共享 Windows 镜像与工具缓存；部署本地 Web、PCJ 或两者，设置版本、端口及 pods。PCJ 支持连接本地 Web，或使用已有账号连接外部 Web。

可获取版本和状态、一键开启、关闭所选服务。关闭只停止所选容器，保留数据、配置、镜像和容器，不停止其他服务或整个 WSL。WSL 虚拟磁盘的 Windows 存放位置仍由 WSL 管理。

### 8. 部署资料与口令导出

按全部或勾选节点导出本机保存的管理员、评测账号及 MySQL root / 业务 / phpMyAdmin 三项口令。配置使用当前 Windows 用户的 DPAPI；私钥仅留在本机。口令导出是明文资料，需单独保管；服务器自行改密后本地旧记录可能不再有效。

## 本版界面修复

- WEB-01：失焦自动保存与“完成”提交串行处理，一次点击即可在保存后关闭弹窗。
- WEB-02：延迟保存响应不再清除期间新勾选的 SSH 连接。
- WEB-03：快速结束的密钥任务也能触发密钥状态和指纹刷新。
- WEB-04：扫描记录全部取消选择后禁止空导入。
- WEB-05：切换缓存版本会清除上一版本的归档路径。
- WEB-06：保存响应不覆盖较新的目标版本输入，并保留焦点和选区。
- WEB-07：跨页面统一锁定冲突操作，避免后台任务并发写入冲突。
- WEB-08：轮询防重入，结果与缓存应用完成后才解除忙碌状态，避免旧响应覆盖新结果。
- WEB-09：长连续路径在 360 像素窄屏换行，不再撑大整个页面。

同时修复 WSL 命令和保活进程继承程序目录的问题，减少发布文件夹被后台进程占用的情况。

## 后续使用与问题反馈

资料默认保存在 `%LOCALAPPDATA%\CSGOJDeploy`，与程序文件分离。升级工具前退出旧程序，保留资料目录；不要在多个工作台进程中同时操作同一资料目录。不会因下载本 Release 自动更新远端站点。

反馈问题时请提供工作台版本、操作步骤、脱敏错误日志和预期结果，不要提交私钥、DPAPI 文件、业务密码或完整数据库。源码开发、打包方法、各模块操作及排障见 README 和 docs。
