## 重跑检查

Windows 源码目录中执行：

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.venv\Scripts\python.exe -m unittest discover -s tests -v
.venv\Scripts\python.exe tests\ssh_check.py
$env:CSGOJ_DEPLOYER_TEST = 'C:\你的目录\csgoj-deploy_2.0.271_linux_amd64'
.venv\Scripts\python.exe tests\browser_check.py
```

浏览器检查默认使用已安装 Microsoft Edge；可设置 `CSGOJ_BROWSER` 指向 Chrome/Edge 可执行程序。

Ubuntu/WSL 中执行：

```bash
python3 /mnt/<盘符>/<源码目录>/tests/linux_ops_check.py
```

这些测试不会连接比赛服务器，也不会安装 Docker或更改主机性能设置。

## 编译与发布

开发环境安装 `requirements-dev.txt` 后运行 `python build.py`。打包采用文件白名单，排除凭据库、私钥、快照、虚拟环境和现有服务器资料。发布目录已有同名产物时会拒绝覆盖该目录。

ZIP 包含运行程序、源码、测试、中文文档、文字验证记录、第三方许可和逐文件 SHA256 清单；不包含验收截图；包外另有 ZIP SHA256 文件。它不是经过代码签名的 Windows 安装程序。

## v1.1 界面和导入
