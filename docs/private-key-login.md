# 外部私钥登录

SSH 管理、OJ Web／评测机节点、管控服务端／选手端以及扫描结果的统一／单机设置，均可填写“私钥绝对路径”和可选的“私钥解锁口令”。新增连接默认 root；已有记录保留原用户名。路径留空沿用原密码或工具管理的密钥逻辑，填写外部私钥后仅使用此私钥，认证失败不回退到登录密码。“测试密码登录”是明确例外，只测试密码。

私钥解锁口令和 sudo／root 提权密码是不同字段；root 登录不进行 sudo 提权。解锁口令保持首尾空格，随连接配置由 Windows DPAPI 加密保存，日志与不含 SSH 凭据的配置导出会剔除该口令。不会把外部私钥路径或口令传入 OJ 远端安装参数。

灰色提示使用通用文字，不包含实际用户名、私钥路径或赛场 IP。本机默认私钥路径单独保存在工具资料目录的 `login-defaults.dpapi`，仅用于新增连接和统一扫描凭据。新电脑首次打开时私钥路径为空；发布 ZIP 不含此文件、私人密钥、已有目标清单或其他本机配置。

管控部署仍使用 WSL Ansible。外部私钥在 Windows 校验／解锁，通过标准输入传入控制器；同一把密钥每个任务只传一份。WSL 在 0700 临时目录中创建 0600 密钥文件，不放在 `/mnt/c`，不放入命令行，正常完成或任务失败后删除。原始密钥保持不变。私钥认证关闭默认密钥搜索与 SSH agent 回退。

Linux 管控目标走 Paramiko SSH；Windows 密码目标走 WinRM HTTPS，Windows 私钥目标走 OpenSSH（空端口默认 22），需目标已开启 OpenSSH、默认 Shell 为 PowerShell，账号具备管理员权限。已有显式端口不会被后端强制改写，请核对实际 SSH 端口。参见 [Ansible Windows SSH 官方说明](https://docs.ansible.com/projects/ansible/latest/os_guide/windows_ssh.html)。SSH 指纹校验仍启用，WSL 控制用户须已信任目标主机；此功能不会关闭指纹校验。

选手端可以先保存未绑定服务端的清单并预览数量。选择服务端后可点“绑定全部待配置机位”，再保存。未绑定清单可以查询状态或仅推送文件，但“一键部署并登记”会在开始前阻止，直到全部目标绑定有效服务端。
